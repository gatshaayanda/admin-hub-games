# Paws World dog sprite provenance

- **Asset:** brown dog sprite sheet (`spritesheet_brown.png`, 96×80 pixels)
- **Author:** Jason of GDN
- **Source:** https://opengameart.org/content/dog-spritesheets
- **Licence:** CC0 (public-domain dedication; the OpenGameArt source page explicitly lists CC0)
- **Use:** single nameable player companion in Paws World. Runtime rendering scales 16×16 source cells with nearest-neighbour sampling.
- **Frame mapping:** current adapter treats rows 0–3 as down/left/right/up movement cycles and columns 0–5 as animation frames. This mapping is an implementation interpretation and should be checked visually on-device.
