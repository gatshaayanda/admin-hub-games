# Free Four-Character Sampler

Version 2.0

Includes Archer, Astronaut, Businessman, and Knight from the full 32x32 Top-Down Character Animation Pack. Each character includes Idle, Walk, Attack, Hit, and Death facing Down, Left, Right, and Up.

Included:
- Spritesheets/Directional: 80 separate one-row PNG animation strips
- Spritesheets/Compact: 20 action sheets and 4 complete character sheets
- 32x32 pixel frame cells, indexed PNG files with transparent backgrounds and the same embedded palette as the full pack

Version 2.0 standardizes the character colors while preserving the original animations, dimensions, layout, and transparency.

The full pack contains 14 characters. See LICENSE.txt for the usage terms.
